ChatShot · Privacy / 隐私说明

PanelEditor · November 20, 2026

截图与保存

仅在你主动操作时截取所选网页内容。图片、续截位置及导出处理在本机完成，不上传聊天内容。临时截图在十天未操作后清理，已导出的文件不受影响。

账号与订阅

免费体验无需登录。选择登录或购买会员时，由 ShipLang 及其登录、支付服务处理相应账号和订阅资料。扩展在本机保存会员状态和试用记录，用于提供已购买的功能。扩展不读取密码，也不接收银行卡资料。

公告消息

扩展可读取GitHub托管的公开公告文件，不附带邮箱、会员资料或截图。GitHub会处理普通网络请求。新品消息可随时关闭。

扩展权限

扩展仅在 ChatGPT 网站自动显示侧栏入口和回答导出按钮；你发起操作后，才读取所选对话用于本机截图与导出。手动截图权限仅在你主动使用时用于当前网页选区；其他权限用于保存文件、记录设置和清理临时截图。

联系与反馈

你可以通过下方联系表单提出支持或隐私请求。表单资料用于处理你的请求，由 Google 托管保存；相关服务按各自政策处理访问请求。

Capture and storage

ChatShot captures selected webpage content only when you invoke it. Screenshots, resume checkpoints, and exports are processed locally; conversation content is not uploaded. Temporary captures are removed after ten inactive days while Chrome is running. Exported files remain under your control.

Accounts and subscriptions

No sign-in is required for the free trial. If you choose to sign in or subscribe, ShipLang and its sign-in and payment providers process the relevant account and subscription information. The extension stores membership status and trial usage locally to provide access. It does not read passwords or receive card details.

Announcements

The extension can retrieve a public announcement file hosted by GitHub without attaching account details or screenshots. GitHub processes ordinary network requests. Product announcements can be disabled at any time.

Extension permissions

Site access is limited to the ChatGPT website to display the sidebar entry and answer export buttons automatically. Conversation content is read for local capture and export when you request it. User-invoked manual capture uses temporary access to the selected current webpage. Other permissions support file saving, local settings and temporary-record cleanup.

Contact

Use the contact form for support and privacy requests. Submitted information is used to handle your request and is stored using Google-hosted services. Those services process access requests under their own policies.
